## 📌 Problem Statement

Predict the category (0–3) assigned to user-generated comments on an online platform, using a mix of:
- **Textual content** (the comment itself)
- **Engagement signals** (upvotes, downvotes, emoticons)
- **Identity metadata** (race, religion, gender, disability flags)
- **Internal system signals** (if_1, if_2)

This is a **severely imbalanced** 4-class classification problem:

| Label | Description | % of Data |
|-------|-------------|-----------|
| 0 | Majority class | 57.66% |
| 1 | Minority | 8.04% |
| 2 | Second largest | 31.54% |
| 3 | Rare class | 2.76% |

## 🔬 Approach

### 1. Exploratory Data Analysis
- Label distribution analysis → identified class imbalance → chose **Macro F1** as evaluation metric
- Comment length distribution (avg: 303 chars, max: 1892)
- Identity feature analysis → comments with identity references shift label distribution toward Class 2
- Correlation heatmap → low feature redundancy, all features add unique signal

### 2. Feature Engineering (198K → 35 features)

| Category | Features |
|----------|----------|
| **Temporal** | hour, day of week, month, is_weekend |
| **Text stats** | comment_length, word_count, avg_word_len, exclaim_count, question_count, upper_ratio, url_count |
| **Engagement** | vote_score, total_votes, vote_ratio, total_emoticons, upvote_log, downvote_log |
| **Identity** | has_identity, identity × if_2 (interaction term) |
| **Combined** | votescore × log(comment_length) |

### 3. Text Representation (TF-IDF)

| Vectorizer | Type | Vocab | Shape |
|------------|------|-------|-------|
| Word TF-IDF | Unigram + Bigram | 20,000 | (118K, 20K) |
| Char TF-IDF | 3–5 grams | 10,000 | (118K, 10K) |

- **Sparse (30,051-dim)** → used for Logistic Regression
- **Truncated SVD (300-dim, 97.36% variance)** → used for LightGBM, XGBoost, MLP

### 4. Models Benchmarked

| Model | Val Macro F1 |
|-------|-------------|
| **Logistic Regression (C=0.5)** | **0.7942** ⭐ best single |
| LightGBM | 0.7540 |
| XGBoost | 0.7517 |
| MLP (256→128→64) | 0.7395 |
| SGD | 0.7187 |
| Random Forest | 0.6977 |
| AdaBoost | 0.5835 |

### 5. Ensemble (Soft Voting)

Systematically explored LR+LGB, LR+LGB+XGB, and LR+LGB+MLP weight combinations.

**Best configuration:**

```
Final Prediction = 0.75 × LR_proba + 0.15 × LightGBM_proba + 0.10 × MLP_proba
```

## 💡 Key Learnings

- On high-dimensional sparse NLP data, **linear models (LR) can outperform tree-based models** — Logistic Regression was the strongest single model
- **Soft ensemble voting** that blends diverse model families (linear + boosting + neural) consistently beats any single model
- **Macro F1** is the right metric for imbalanced multiclass problems — accuracy would have been misleading (a naive classifier predicting Class 0 always gets 57% accuracy)
- Character-level n-gram TF-IDF captures sub-word patterns that word-level TF-IDF misses
